# CSV report

## Rules

- Report the number of data rows, excluding the header.
- Report missing values separately for each column.
- Keep rows with missing cells in the row count.
- Use the [report template](references/report-template.md) when asked for a structured report.

## Example

A CSV with 12 data rows and two missing dates has 12 rows and two missing values in the date column.
